# Curriculum

The supplied app defines eight syllabus sections, six complete guides and three live skill IDs. The build handoff describes the pilot as a decision, feedback and revision loop. The Swiggy scenario, data exercises and reading assignments are newly authored additions to the existing Problem Framing path.

All three PM stages can choose any live skill. Complete a Pre-Read to unlock Quick Drill. Complete a drill set to unlock Gym Room. Progress opens at 30 XP. Repeating a rewarded item retains its existing XP key. Wrong answers return in the retry queue; the existing first-try and review counters still apply.

| Pilot step | Skill and activity ID | Outcome | Available after |
|---|---|---|---|
| Pre-Read | product / framing | Separate observation from hypothesis and name a test. | First skill selection |
| Quick Drill | product / qd-swiggy | Compare two cohorts, select two causes, compute conversion and pair checkout branches. | One guide marked read |
| Gym Room | product / gr-swiggy | Save an investigation, update it after provider evidence and self-assess with the six-dimension rubric. | One drill set finished |
| Progress | progress | Revisit practice activity and XP. | 30 XP |
